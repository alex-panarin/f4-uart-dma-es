# Четыре режима питания

Режим         Ядро        Такты Периферия   Память  Ток (типовой, MCU)   Пробуждение
Run           работает    все   вся         —       ~15 мА @ 84 МГц       —
Sleep         остановлено идут  жива        да      ~3–5 мА любой         IRQ
Stop          остановлено стоят стоит       да      десятки мкА           EXTI / RTC
Standby       обесточено  стоят обесточена  нет     ~2 мкА                WKUP / RTC

Нас интересуют Sleep и Stop. Standby теряет SRAM и требует отдельного сценария

Что происходит с нашим хозяйством
Модуль                  Sleep                 Stop
DMA2 (UART RX/TX, SPI)  работает              стоит
USART1                  принимает/передаёт    тактов нет, приём невозможен
SPI1 + W25Q             работает тактов нет;  сама флеш сохраняет данные
SRAM (кольцо, слоты, буферы) жива             жива
DWT CYCCNT              под вопросом           не считает (ядро без тактов)
RCC (PLL, делители)     без изменений         сбрасывается: SYSCLK = HSI

## Источники пробуждения и цена каждого

Источник                            Плюс                            Минус
Кнопка на EXTI                      чисто, данных не теряем         нужен пин и кнопка
Активность UART RX (EXTI на PA10)   не требует железа, будит хост   первый байт теряется — USART без тактов
RTC alarm / wakeup                  точное время, периодика         ----

STOP спали ~500 мс
  настенное время:   551.1 мс

  источник тактов:   PLL

python power_bench.py -p COM5 verify
PING 10 мс: 84.001 МГц

python power_bench.py -p COM5 stats
PWR: sleep=2 stop=1 wake_exti=1 clock_restores=1
     drain_timeouts=0 last_wake=60 cycles (0.7 мкс) rx_flushed=1

В stats смотрим rx_flushed — сколько байт отброшено после сна.
Это и есть цена пробуждения активностью линии: преамбула создана ради того,
чтобы устройство проснулось.
Ожидание: rx_flushed порядка числа посланных преамбульных байт (0…4, зависит
от момента восстановления тактов).
